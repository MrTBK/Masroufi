# Roadmap (post-MVP)

## V1.1 candidates
- Recurring transactions (daily/weekly/monthly/yearly, month-boundary safe)
- Debt tracking + partial payments
- Savings goals + contributions/withdrawals
- Category budgets + budget alerts
- Improved reports + rule-based insights
- PDF export, reminders, app lock

## V1.2 candidates
- Cloud backup + sync (repos already use stable UUIDs + timestamps)
- Receipt attachments, receipt OCR
- Family/shared budgets

## V2 candidates
- Tunisian integrations where officially supported, advanced analytics,
  optional AI features (read-only analytics queries; never direct DB mutation).
