2. WHAT THE APP DOES (screens)
----------------------------------------------------------------
- Onboarding: choose language (ar/fr/en) -> first wallet + starting balance
  (+ optional name) -> theme -> dashboard. No account, skippable optionals.
- Dashboard (/): total balance, month income / expenses / remaining, budget
  bar, recent transactions, top spending categories, quick actions with a
  dominant Expense button, bottom nav (Dashboard/History/Wallets/More).
- Add/Edit form (/add?type=expense|income|transfer): amount first (numeric
  keyboard, autofocus), category dropdown, wallet dropdown(s), date picker,
  note, save. Transfer = from/to wallets, never counted as spend.
- History (/history): search, type chips, wallet/category/date filters,
  edit on tap, swipe-to-delete (confirm), duplicate on long-press.
- Wallets (/wallets): create/rename/archive, derived balances, per-wallet
  history dialog.
- Categories (/more/categories): 20 Tunisian defaults (Café, Taxi, Louage,
  Bus, Metro, Fuel, STEG, SONEDE, Internet, Mobile, Groceries, Restaurants,
  Fast Food, Clothing, Electronics, Household, Health, Entertainment, Gym,
  Other) translated in 3 languages + custom create/rename/archive.
  Archiving never breaks history (no FK constraints by design).
- Monthly budget (/more/budget): one overall budget per month with spent /
  remaining / percent + over-budget warning; edit/delete.
- Reports (/more/reports): monthly total, income-vs-expense bars,
  by-category bars (custom widgets, no chart dependency).
- Backup (/more/backup): versioned JSON backup (save dialog), validated
  restore (destructive-confirm), UTF-8-BOM CSV export (Excel-compatible).
- Settings (/more/settings): language, theme (system/light/dark), user name.

  12.500 / 12,500 / 1,250.500; formatting e.g. "12.500 د.ت" (ar) /
  "12.500 TND". No double anywhere in finance math (lib/core/money/).

4. ARCHITECTURE
----------------------------------------------------------------
UI widgets -> Riverpod providers (lib/app/providers.dart) -> repository
classes (lib/data/repositories/) -> Drift AppDb (lib/data/database/) ->
SQLite file (app_flutter/masroufi.sqlite on device). No logic in widgets.
Repos use stable UUID ids + createdAt/updatedAt (sync-ready for V1.2+).
Tables (schema v1): wallets, categories, transactions (type expense|income|
transfer; transfer = single row with to_wallet_id), budgets (unique
year+month), app_settings (language/theme/onboarding_done/user_name).
Indexes on transactions(date, wallet, category, type). Balances DERIVED
(initial + income - expense + transfersIn - transfersOut), never stored.

----------------------------------------------------------------
5. LOCALIZATION / OFFLINE / SECURITY
----------------------------------------------------------------
- Hand-rolled EN/FR/AR string tables (lib/core/l10n/strings.dart), no codegen;
  genuine RTL (Material locale + Directionality), intl dates/numbers.
- Fully offline: zero network permission for core features; no account.
- Secrets hygiene: ~/.masroufi/ keystore (4096-bit RSA, 25y) outside git;
  android/key.properties git-ignored; release signing with debug fallback;
  secret scan clean. PRIVACY.md + store/privacy-policy.md state: no data
  leaves the device.
