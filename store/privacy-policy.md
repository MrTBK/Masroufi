# Privacy policy — Masroufi (for store listing)

Last updated: 2026-09-10. Contact: provided at release time.

Masroufi is an offline-first personal finance app. Your ledger stays
on your device. Core finance works in airplane mode with no account.

1. No account. All core features work without registration or sign-in.
2. Local storage only. Wallets, transactions, categories, budgets and settings
   are stored in an on-device SQLite database. There is no backend server
   for money.
3. Ads (opt-in, Google AdMob, off by default). When enabled in
   Settings → Privacy & Ads, Google may collect Advertising ID, app
   interactions, and performance data to show ads. Data collected by
   Google, shared with Google for advertising. PRO disables all ads.
4. Cloud AI (opt-in, off by default). When enabled and you tap Explain,
   a redacted summary (totals only, no notes by default) is sent to our
   proxy → LLM. No auto-sending. Planning aid, not financial advice.
5. Network use only for ads / AI when opted in. All finance features
   work offline.
6. Backups and exports (JSON backup, CSV) are created only when you ask, saved
   to your device, and shared only through the system file UI you control.
7. Permissions used: INTERNET + ACCESS_NETWORK_STATE (ads/AI opt-in only),
   AD_ID (AdMob with consent), USE_BIOMETRIC (app lock),
   POST_NOTIFICATIONS (optional digest). File picking via system picker.
   Camera, contacts, location, microphone never requested.
8. Children: general personal-finance tool with no age-gated content;
   accounts are not created.
9. Changes to this policy will be published with app updates.
