# Privacy policy — Masroufi (for store listing)

Last updated: 2026-09-06. Contact: provided at release time.

Masroufi is an offline-first personal finance app. Your financial data stays
on your device.

1. No account. All core features work without registration or sign-in.
2. Local storage only. Wallets, transactions, categories, budgets and settings
   are stored in an on-device SQLite database. There is no backend server.
3. No analytics, advertising, or tracking SDKs. The app collects nothing.
4. No network use for core features. The app requests no network permission
   for tracking money; all finance features work in airplane mode.
5. Backups and exports (JSON backup, CSV) are created only when you ask, saved
   to your device, and shared only through the system file UI you control.
6. Permissions used: none beyond what file picking requires via the system
   document picker. Camera, contacts, location, and microphone are never
   requested.
7. Children: the app is a general personal-finance tool with no age-gated
   content; accounts are not created.
8. Changes to this policy will be published with app updates.
